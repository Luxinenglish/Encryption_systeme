
# Contributors

Merci à toutes les personnes qui contribuent à ce projet.

## Mainteneur principal

- **Lux_** - Créateur du projet et développement principal

## Comment contribuer

1. Fork du projet
2. Créer une branche (`feature/ma-feature` ou `fix/mon-fix`)
3. Commit clair et ciblé
4. Ouvrir une Pull Request

## Règles de contribution

- Respecter la structure existante (`app.py`, `crypto.py`, `widgets.py`, etc.)
- Garder le code lisible et simple
- Ajouter une description claire de chaque changement
